# Electrosining system

Electrospinning is the process of spinning a filament of material (such as nylon) on a spinning machine. This process is used in the production of fiber products, such as yarn, thread, and netting.

## Device function

- Siringe pump control via stepper motor
- Temperature control via triac
- Humidity control via triac
- Rotari colector control via DC motor driver control via L298N
- UI interface made with Encoder and SSD1306 display
- Communication with ESP32-S3 via UART
- Communication with ESP32-S3 via MQTT
